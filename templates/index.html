Project Objective

Build an automated tool that scans source code to find security bugs early in the development lifecycle, providing developers with quick feedback and clear remediation advice before code goes live.

How It Works

SecureLens uses Static Application Security Testing (SAST) to analyze code structure using pattern matching, AST analysis, and regex-based detection to identify vulnerabilities without executing the code.

OWASP Coverage

Covers major OWASP Top 10 (2021) categories including Injection, Cryptographic Failures, Sensitive Data Exposure, Security Misconfiguration, and Software Integrity Failures.

Supported Languages

Scans Python, JavaScript, TypeScript, Java, PHP, Go, Ruby, C#, HTML, and configuration files for security vulnerabilities.
